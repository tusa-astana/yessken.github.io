Политика конфиденциальности

1. Оператор

Оператор сервиса — команда TUSA. По вопросам обработки персональных данных обратитесь в службу поддержки TUSA в Telegram.

2. Какие данные мы получаем

В зависимости от действия сервис может получать Telegram ID, имя, username, язык, фото профиля, выбранные интерес-группы и настройки видимости, созданные или выбранные встречи (дата, время, публичное место и запись на участие), данные заявки организатора, контактный email или телефон, сведения о событии, цифровой подписке, жалобе на поведение в сообществе и технические данные обращения в поддержку. Для аналитики события могут учитываться открытия страницы и переходы по ссылке; если запрос подтверждён Telegram initData, он может быть связан с Telegram ID. Новые отметки «Вместе» анонимны по умолчанию: имя и фото скрыты, пока пользователь явно не включит показ профиля; username раскрывается только при отдельном согласии на знакомства.

3. Для чего данные используются

  • для авторизации и защиты аккаунта через Telegram initData;
  • для подбора сообществ по интересам и управления участием в них;
  • для обработки жалоб на спам, преследование, выдачу себя за другого и другое небезопасное поведение; жалобы проверяет модератор;
  • для обработки заявки на размещение события и связи с организатором;
  • для показа организатору агрегированных открытий, shares и RSVP по его одобренным событиям; открытия могут включать повторные посещения и не являются уникальным охватом или продажами;
  • для управления цифровой подпиской Organizer Pro и поддержки Stars-платежа, если подписка включена;
  • для предотвращения злоупотреблений, ведения журнала обращений и улучшения сервиса.

RSVP — это отметка интереса/участия, а не билет или бронирование. Сервис не запрашивает и не использует сведения о зависимости или состоянии здоровья для отбора участников. Решения модерации основаны на конкретном поведении и нарушениях правил.

4. Передача данных

Для работы сервиса данные могут обрабатываться Telegram, хостингом и техническими подрядчиками оператора. Если Organizer Pro будет включён, Stars-платёж обрабатывает Telegram; TUSA получает только сведения о транзакции и её статусе, необходимые для активации услуги, поддержки и возврата. TUSA не использует сторонний платёжный провайдер и не получает данные банковской карты. Мы не продаём персональные данные.

5. Срок хранения и права пользователя

Данные хранятся столько, сколько необходимо для работы сервиса, исполнения заказа, поддержки, бухгалтерского и юридического учёта. Пользователь может запросить уточнение или удаление данных, если их сохранение не требуется законом или незавершённым заказом.

6. Обращения

По вопросам обработки данных используйте службу поддержки TUSA в Telegram.
